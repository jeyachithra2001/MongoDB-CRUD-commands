#MongoDB CRUD Operations 

📌 Project Overview

This project demonstrates practical implementation of CRUD (Create, Read, Update, Delete) operations using MongoDB. It focuses on managing documents in collections, performing database queries, and applying query operators through hands-on practice.

🎯 Objectives

- Understand MongoDB database and collection operations.
- Perform CRUD operations using MongoDB.
- Practice filtering and searching documents.
- Use query operators to retrieve specific data.
- Implement a real-world use case using MongoDB.

🛠️ Technologies Used

- MongoDB
- MongoDB Shell (mongosh)
- JavaScript

📚 Tasks Implemented

1. Insert Operations

- Insert a single document using "insertOne()".
- Insert multiple documents using "insertMany()".

2. Read Operations

- Retrieve all documents using "find()".
- Retrieve a single document using "findOne()".
- Filter documents using specific conditions.

3. Update Operations

- Update a single document using "updateOne()".
- Update multiple documents using "updateMany()".

4. Delete Operations

- Delete a single document using "deleteOne()".
- Delete multiple documents using "deleteMany()".

5. Query Operators

Practiced the following MongoDB query operators:

- "$gt" – Greater than
- "$lt" – Less than
- "$in" – Matches any value in an array
- "$and" – Matches all specified conditions
- "$or" – Matches at least one condition
- "$exists" – Checks whether a field exists

6. Practical Use Case

Created a small database use case to apply MongoDB operations in a real-world scenario.

- Insert records into a collection.
- Retrieve records based on specific conditions.
- Update individual and multiple records.
- Delete records based on conditions.
- Search and filter data using query operators.

💡 Key Learnings

- Understanding MongoDB document structure.
- Working with databases and collections.
- Performing CRUD operations.
- Writing queries using comparison and logical operators.
- Managing and manipulating documents efficiently.

🚀 Conclusion

Successfully practiced MongoDB CRUD operations and query operators through hands-on exercises. This project helped strengthen my understanding of MongoDB database management and real-world data manipulation.
